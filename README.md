# ReciclaCDMX

ReciclaCDMX es una página web que tiene como objetivo mostrar información sobre reciclaje, materiales reciclables y algunos centros de reciclaje.

## Versión

0.1.0

## Tecnologías

- HTML5
- CSS3
- Visual Studio Code

## Requisitos

Para visualizar el proyecto se necesita:

- Un navegador web como Google Chrome, Safari o Microsoft Edge.
- Tener la carpeta completa del proyecto.

## Ejecución

1. Abrir la carpeta ReciclaCDMX.
2. Abrir el archivo `index.html`.
3. El proyecto se abrirá en el navegador.
4. Utilizar el menú para navegar por las diferentes páginas.

## Estructura

ReciclaCDMX/

- index.html
- centros.html
- detalle.html
- materiales.html
- consejos.html
- css/
  - estilos.css
- img/
- README.md

## Funcionalidades actuales

Actualmente el proyecto permite:

- Visualizar la página principal.
- Consultar algunos centros de reciclaje.
- Ver información detallada de un centro.
- Consultar diferentes materiales reciclables.
- Ver consejos relacionados con el reciclaje.
- Navegar entre las diferentes páginas.

## Estado

El proyecto se encuentra en su primera versión.

Actualmente cuenta con páginas HTML, estilos CSS y navegación entre las diferentes secciones. El contenido es estático y todavía no utiliza PHP ni base de datos.
